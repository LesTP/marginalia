# Previous drafts and prototypes

Superseded presentation experiments for this corpus, kept for reference. The
current reading view is `../review.html` (the continuous synchronized note
corpus design).

- `review-before-reading-model.html` — early archived review captured before the
  reading model (plain reading, lenses, guided pathways) was introduced.
- `review-text-as-space-mockup.html` — first interaction prototype: click a
  passage to retrieve its notes, with one canonical commentary panel.
- `review-generated-shared-renderer.html` — the deterministic output of the
  shared Python renderer (`reference-corpus-render`), using the accordion layout.
  Regenerating with the shared renderer will not touch `../review.html`, which is
  now maintained as a hand-authored reading view.
